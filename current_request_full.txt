# PHASE 2 — Boot Performance Optimization

Investigate and optimize the actual bottlenecks.

## A. Hardware Initialization

- Find unnecessary repeated hardware probing.
- Check for excessive device polling.
- Identify long timeout loops.
- Check ATA/AHCI initialization and missing-device fallback.
- Check ACPI and APIC discovery.
- Check timer initialization.
- Identify blocking hardware operations.
- Avoid probing unsupported devices repeatedly.
- Ensure failed optional devices do not block desktop startup indefinitely.

Do not remove required hardware checks.

## B. Storage and Filesystem

- Inspect disk detection and initialization.
- Find unnecessary repeated filesystem scans.
- Check mount-time metadata validation costs.
- Avoid repeated initialization of the same device.
- Identify blocking flushes or timeout loops during startup.
- Preserve filesystem integrity and crash recovery guarantees.

Do not skip filesystem integrity checks merely to improve boot time.

## C. Kernel Initialization

- Inspect synchronous initialization dependencies.
- Identify operations that can safely happen after desktop startup.
- Separate essential initialization from optional services.
- Avoid initializing subsystems twice.
- Remove redundant work only after proving it is redundant.

Do not move initialization asynchronously if another subsystem depends on its completion.

## D. Networking

- Investigate whether network initialization blocks the boot sequence.
- Avoid waiting indefinitely for DHCP, DNS, or external connectivity.
- Use bounded timeouts.
- Allow the desktop to start without network connectivity if networking is optional.

Do not falsely report network readiness.

## E. Scheduler and Process Startup

- Identify processes that block desktop initialization.
- Investigate excessive scheduling delays.
- Ensure startup processes terminate or yield correctly.
- Avoid busy waiting.
- Check for lock contention and deadlocks.
